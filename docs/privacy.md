# Privacy

The bridge does not request or export browser credentials. It can nevertheless act through existing authenticated browser sessions.

Browser-derived text, screenshots, accessibility data, and tool results may enter the Claude conversation and be processed under Anthropic's terms and retention controls. OpenAI's extension, native host, and local runtime remain subject to OpenAI's policies.

The bridge has no telemetry. It must not log browser payloads, cookies, tokens, file contents, or form values.
